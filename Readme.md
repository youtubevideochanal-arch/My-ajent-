# MY AGENT - AI Assistant

Yeh ek advanced AI Agent application hai jo Android phone ko control karta hai, trading mein help karta hai, aur social media manage karta hai.

## Features
- 🎙️ Voice Command Support
- 🤖 Multi-API Fallback (Gemini, OpenAI, Claude, etc.)
- 📱 Phone Control (Accessibility Service)
- 📈 Trading Assistant (Real-time analysis)
- 🎨 3D Animated UI with ON/OFF Switch

## Setup Instructions
1. Clone this repository.
2. Open in Android Studio.
3. API Keys app ke andar 'Settings' menu se add karein (Security ke liye code mein hardcode na karein).
4. Build and Run.

**Note:** Yeh project abhi development phase mein hai.
